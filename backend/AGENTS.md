# AGENTS.md

FastAPI backend for the EduRed Huancayo educational-resource catalog. Python 3.14
(`.python-version`), managed with uv (`uv.lock`). Data lives in **SQL Server**
(`EduRedHuancayo`); the schema and seed catalogs are in `sql/schema.sql`.

## Commands

- Sync dependencies: `uv sync`
- Run dev server (from `edu/backend`):
  `uv run uvicorn backend.main:app --app-dir src --reload`
- Docs: http://127.0.0.1:8000/docs — uploads served at `/uploads/<file>`
- Tests (no DB needed): `uv run python -m unittest discover -s tests -v`
- Fallback environment: if Windows blocks `.venv` (`os error 5` / `Access is denied`,
  usually because a Uvicorn process still holds it), stop that process first, or use
  the pre-synced `.venv2` with `$env:UV_PROJECT_ENVIRONMENT=".venv2"` before both
  `uv sync` and the server command. `.venv2` is gitignored.
- Do **not** use `uv run backend`: the `[project.scripts]` entrypoint is a stub in
  `src/backend/__init__.py` that prints "Hello from backend!".

The package is installed editable from `src/` by `uv_build`, so imports are
`backend.*` (never `src.backend.*`).

## Layout and flow

Request flow: `apis/` -> `services/` -> `repositories/` -> `database.py` (pyodbc).

- `src/backend/main.py` — app setup, CORS (`ORIGENES_FRONTEND` env var, defaults to
  both Angular dev origins), `/uploads` static mount, domain + `pyodbc.Error` handlers.
- `src/backend/apis/recursos.py` — CRUD routes and multipart upload validation.
- `src/backend/apis/usuarios.py` — registration, `/auth/login`, `/auth/me`, Bearer dep.
- `src/backend/apis/mentorias.py` — mentorship requests (optional authenticated user).
- `src/backend/services/` — business rules, domain exceptions, Argon2 password
  hashing and HS256 JWT session tokens (`seguridad.py`).
- `src/backend/repositories/` — parameterized SQL against `dbo.Recursos`,
  `dbo.Usuarios`, `dbo.Mentorias`, with catalog lookups on `dbo.Categorias`/`dbo.Roles`.
- `src/backend/schemas/` — Pydantic request/response models.
- `src/backend/database.py` — connection factory from `.env`.
- `sql/schema.sql` — reconstructs the normalized (3FN) schema and seeds catalogs.

Raise domain exceptions from `services/`; let `main.py` map them to HTTP responses
instead of raising `HTTPException` in that layer. Keep identifiers, messages, and
docstrings in Spanish, matching the existing code.

## API quirks

- IDs are generated by SQL Server (`INT IDENTITY`) and returned as `int`; the client
  must not send an `id` when creating a resource.
- `POST /recursos` takes **multipart/form-data** (`titulo`, `categoria`, `autorFuente`,
  `descripcion`, optional `archivo`), not JSON. `PUT /recursos/{id}` is JSON and cannot
  change `id` or `archivo_url`.
- `categoria` is validated against `dbo.Categorias` (400 `CategoriaNotFoundError`).
- Attachments: `.pdf .doc .docx .ppt .pptx`, MIME allowlist, max 10 MB. Stored as
  `<uuid4hex><ext>` in `uploads/` and exposed as `/uploads/<name>`.
- `uploads/` lives at the repo root and is gitignored. Its path is derived relative to
  `src/backend/config.py`, so keep the editable install/repo layout.
- Registration is always `estudiante` (server ignores any other requested role).
  Passwords are hashed with `argon2-cffi`; login returns a JWT (HS256) valid for 8
  hours. Configure a strong `SECRETO_APP` in `.env` for anything beyond local
  development.
- Deleting or updating a resource leaves its old uploaded file on disk (no cleanup).
